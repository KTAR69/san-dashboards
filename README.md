# Substrate-Aware Network (SAN) Dashboards 🛰️

Public interactive web instruments for **[T.A. Resendez Inc.](https://taresendezinc.com/)**, accessible directly and featured on the **[On Radar](https://taresendezinc.com/on-radar-1)** portal.

These browser-based visualizations serve as public-tier instruments illustrating live radar tracking and structural convergence across terrestrial, orbital, and decentralized network substrates.

---

## 🧭 Live Public Instruments

| Instrument | Description | Live Link |
| :--- | :--- | :--- |
| **Live SAN Radar** | Real-time radar visualization tracking active frontiers across DLT, DePIN, and edge telecommunications | [Launch SAN Radar](https://ktar69.github.io/san-dashboards/SAN_Radar_Public.html) |
| **Iceberg x HybridTongue Convergence** | Visualizing layered substrate convergence across classical and decentralized systems | [Launch Convergence Dashboard](https://ktar69.github.io/san-dashboards/Iceberg_x_HybridTongue_Convergence_classical_v1.html) |

> *Note: These two instruments represent the public-tier fleet. Advanced instruments and full-fleet telemetry are distributed through [The Substrate Report](https://thesubstratereport.substack.com/).*
